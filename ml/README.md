# ML Coursework — Overview

This directory contains short, focused Jupyter notebooks for machine learning topics covered in the coursework. Notebooks demonstrate concepts, typical workflows, and runnable examples you can open in Jupyter or VS Code.

What's here (short):
- 01-data-preprocessing: data cleaning, feature engineering, scaling, and encoding.
- 02-regression-models: linear and polynomial regression examples and evaluation.
- 03-tuning-and-validation: cross-validation, hyperparameter search, and model selection.
- 04-classification-models: classical classifiers (Naive Bayes, KNN, SVM, decision trees, random forest, boosting) and examples.
- 05-neural-network-for-regression: NN approaches for regression tasks.
- 06-neural-network-for-classification: simple feedforward NN classifiers.
- 07-dropout-normalization: regularization techniques (dropout, batch/layer norm).
- 08-CNN: convolutional neural network examples for image tasks.
- 09-RNN: recurrent networks and sequence models.

Quick start:
- Install Python 3.8+ and Jupyter
- Install common packages: scikit-learn, pandas, numpy, matplotlib; for NN notebooks also install tensorflow or pytorch as required by each notebook.
- Open the desired notebook and run cells.

Notes:
- Each notebook is designed to be self-contained with short explanations and runnable cells.
- See the root README for overall project context.
